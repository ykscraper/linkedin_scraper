# LinkedIn Jobs Scraper

## Project Overview

This project is designed to extract job listing information from LinkedIn using Python.

It collects job details and organizes the extracted data into an Excel spreadsheet for easy viewing and analysis.

## Features

- Extracts job titles
- Collects company names
- Extracts job locations
- Collects clickable job URLs
- Organizes job data into structured tables
- Exports results to Excel

## Data Fields

| Field | Description |
|---|---|
| Job Title | Name of the job position |
| Company | Company offering the job |
| Location | Job location |
| Job URL | Direct link to the job listing |

## Technologies Used

- Python
- Web Scraping
- Excel
- Data Extraction

## Project Workflow

1. Open LinkedIn job search results.
2. Extract available job listing information.
3. Collect job titles, company names, locations, and URLs.
4. Organize the collected data.
5. Export the results into an Excel file.

## Output

The extracted job data is saved in an Excel spreadsheet with clickable job URLs.
